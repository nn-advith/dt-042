DT-042 Requirements and Features

Initial Toolset:

1. Notes utility:
    - Create/ Edit/ Delete notes
    - Color code
    - Date and time of creation; display inconspicuously
    - auto save from other notes tag with origin tool
2. Base64 Encoder/Decoder
    - Text to B64 and vice versa
    - store to notes; auto click ----> make this save thing cross-tool set
3. Color pallette saver
    - mouse based color picker
    - ability to input hex/rgb/hsv to search for colors
    - 2/3/4/5 color pallette options
    - list of  pallettes; uniform way to display them;
    - name, tag each pallette
    - edit, delete pallette
    - export image with cool design to share pallette
4. Regex validator
    - input for regex and input
    - hightlights for matching parts; live
    - errors and error print
    - save to note with expression and matches list
5. Cronjobs
    - english translation in real time; relative to current time
    - common expressions
    - reference legend
    - save to note with description
6. API client (simple)
    - GET/POST/PUT/ and other headers
    - url, body , query params, auth 
    - save request format for later use
    - convert request and response to notes
7. Text compare
    - live text compare
    - per line comaprison
    - hightlight differences
8. JSON viewer/formatter/stringify/parse
    - tree view with expandable bocks
    - colored hightlights in tree view
    - format button for beautify
    - validate the json and show errors ( live or on button click)
